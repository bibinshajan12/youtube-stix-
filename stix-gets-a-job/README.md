# Stix Gets a Job

A 20-episode YouTube Shorts package for the What If STIX workplace-satire series.

## The comedy engine

Stix confidently renames each workplace failure with impressive jargon. Twig identifies and fixes the real operational problem. Senior management rewards Stix, then warns Twig for bypassing the process that caused the failure.

## Production package

- [20 complete workplace Shorts scripts](./20-workplace-shorts-scripts.md)
- Each episode includes a title, first-frame hook, complete dialogue, timed visual plan, management punchline, comment prompt, and subscribe call to action.
- Spoken copy was paced for an approximately 50-second vertical Short, with visual reaction beats completing the edit.
- The package includes a recommended release order and recurring visual rules for the Promotion and Burnout meters.
